# RSsimulacion - Simulación 3D de Repuestos Sotomayor

Simulación 3D interactiva desarrollada con **Three.js** que recrea el local comercial de **Repuestos Sotomayor** y su entorno en la **Av. Michelena**.

## 🚀 Características

- **Entorno 3D Interactivo**: Modelado procedural en Three.js con iluminación, sombras y texturas detalladas.
- **Controles de Cámara y Órbita**: Navegación libre, vistas preestablecidas y controles HUD.
- **Interfaz Moderna**: Panel de control con diseño translúcido (Glassmorphism) y Tailwind CSS.
- **Sin dependencias de compilación**: Funciona directamente en cualquier navegador moderno abriendo `index.html`.

## 🖥️ Cómo ejecutar localmente

1. Clona el repositorio:
   ```bash
   git clone https://github.com/VicD4ddy/RSsimulacion.git
   cd RSsimulacion
   ```
2. Abre `index.html` en tu navegador favorito (o usa un servidor local como Live Server, Vite o `python -m http.server`).

## 🛠️ Tecnologías

- [Three.js](https://threejs.org/) (r128)
- [Tailwind CSS](https://tailwindcss.com/)
- JavaScript Vanilla
